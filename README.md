### 📊 Financial Health Index (FHI) Prediction using Machine Learning

This project focuses on building a **Machine Learning classification model** to predict **Financial Health Index (FHI)** categories (**Low, Medium, High**) based on structured financial data.

The workflow includes **data cleaning, feature engineering, model training, evaluation, and prediction generation** using **LightGBM**, a high-performance gradient boosting framework.

NOTE :-The dataset is not included in this repository due to data usage restrictions.

---

### 🔧 Technologies Used

* Python
* Pandas, NumPy
* Scikit-learn
* catboost 
*  Google Colab

---

### 🚀 Project Workflow

1. Data preprocessing and cleaning
2. Feature selection & transformation
3. Model training using LightGBM Classifier
4. Model evaluation (Confusion Matrix & Classification Report)
5. Prediction generation and CSV submission file creation

---

### 📈 Output

* Predicted FHI categories: **Low / Medium / High**
* Final predictions saved as `submission.csv`

---

### 🎯 Objective

To demonstrate an **end-to-end ML pipeline** for classification problems, focusing on model performance, clean code, and reproducibility.
